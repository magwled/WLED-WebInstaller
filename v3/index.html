          Troubleshooting
          

            
No device found?

            
You might need USB-to-serial drivers for your board:

            CP2102 driver (square chip)
            CH34x driver (rectangular chip)
            
Make sure your USB cable supports data transfer (not charge-only).


            
Install failing or device stuck in a boot loop?

            
Some boards require you to hold the BOOT button while plugging in the USB cable (or while clicking Connect) to enter flashing mode. Release the button once the connection starts.
